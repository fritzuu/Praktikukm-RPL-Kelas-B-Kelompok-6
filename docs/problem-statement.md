# Problem Statement - SARS

Civitas akademik Prodi Informatika (Admin, Aslab, Mahasiswa, dan Dosen) mengalami kesulitan dalam mengelola dan melacak perubahan jadwal perkuliahan secara terpusat ketika terjadi kebutuhan penggantian kelas, baik yang bersifat sementara (hanya berlaku 1 pertemuan spesifik) maupun permanen (mengubah template rutin ke depannya). Hal ini menyebabkan risiko bentrok ruangan, miskomunikasi antar pihak, dan tidak beraturannya pencatatan riwayat jadwal.

Solusi berupa sistem Smart Academic Schedule & Room Change System (SARS) terintegrasi berbasis Web Application dan Android App diharapkan dapat memfasilitasi alur persetujuan yang tervalidasi, menjaga integritas jadwal *baseline*, dan memastikan seluruh pengguna mendapat informasi secara *real-time*.

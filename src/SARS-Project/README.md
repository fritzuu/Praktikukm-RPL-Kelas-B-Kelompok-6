# SARS (Sistem Akademik & Ruang Studi) Project

Proyek ini adalah platform terintegrasi untuk mahasiswa, dosen, asisten lab, dan administrator dalam mengelola jadwal perkuliahan. Dibangun menggunakan Laravel (Backend), React/Inertia.js (Frontend), dan Supabase PostgreSQL (Database).

> [!IMPORTANT]
> **Panduan Setup & Dokumentasi Utama:**
> Untuk menghindari perbedaan versi dokumentasi, panduan setup lengkap (termasuk instalasi Laravel Reverb, WebSockets, akun uji coba, dan troubleshooting) kini dipusatkan di berkas **[README.md di Root Repositori](../../README.md)**.
> 
> Silakan merujuk ke berkas tersebut untuk langkah-langkah instalasi dan menjalankan proyek dalam mode pengembangan.
